# IWFTM — поиск музыки по FMHY

Откройте start.cmd двойным щелчком. Нужен Python 3.11 или новее, дополнительные библиотеки не нужны. Интерфейс: http://127.0.0.1:8765. Закрытие окна сервера останавливает приложение.

Введите исполнителя, альбом или трек. «Все доступные» выбирает источники с отвечающим поиском. «Только lossless» выбирает среди них сайты с заявленным FLAC/ALAC/lossless. Фильтр списка источников меняет отображение, но не снимает выбор. Фильтр результатов работает по качеству конкретной записи.

## Охват и проверка

Обработан полный каталог FMHY: потоковые каталоги, концерты, Audio Ripping Sites, Download Sites, жанровые разделы, торренты, свободная музыка и саундтреки. Обновление использует официальный репозиторий https://github.com/fmhy/edit/blob/main/docs/audio.md, поскольку основная страница возвращала HTTP 403.

Проверено 268 уникальных доменов: 29 дали распознанные результаты, 36 ответили на поисковый запрос без распознанных совпадений, 203 недоступны или требуют другого интерфейса. Для автопоиска включены первые 65 сайтов, из них 20 с заявленным lossless. Ответ формы без совпадений не доказывает исправность поиска. Подробности: SOURCES-AUDIT.md и sources.json. В inventory.json отражены 1173 основные и вспомогательные ссылки с причинами исключений; это не 1173 независимых музыкальных сервиса.

Подключены публичные поисковые API ARCOD и TIDAL DL, обнаруженные в их собственных веб-клиентах. Они возвращают треки/альбомы и параметры каталога. Скачивание через сервис не проверяется; ARCOD сохраняет флаг downloadable, включая false. Карточки предлагают открыть сервис и вставить указанную ссылку или название. Прямой переход к внутренней карточке не имитируется.

HTML-поиск поддерживает GET/POST, распространённые WordPress/DLE-формы, поля Drupal, Metal Tracker и DoujinStyle. Khinsider: качество из таблицы треков; Music Rider: из блока описания. API Internet Archive подключён, но при проверке отвечал тайм-аутом TLS.

## Ограничения

- HTML: 1–5 страниц на сайт, переход только по распознанной ссылке следующей страницы. Сохраняются все распознанные URL в этих пределах. Автоматически читаются до 12 описаний релизов на сайт, остальные — кнопкой в карточке.
- ARCOD: до пяти порций по 10 треков и 10 альбомов. TIDAL DL: 25 треков, поскольку пагинация публичного клиента не подтверждена. Неполная выдача отмечается.
- До 6 источников одновременно. Остановка не запускает следующие сайты, но ждёт текущие запросы.
- Качество берётся из метаданных, аудиофайлы не анализируются. Lossless сортируется выше сжатых форматов, затем учитываются разрядность и частота. Битрейт альтернативного MP3 не повышает рейтинг lossless. M4A не считается lossless автоматически.
- HTML-ссылки сопоставляются по минимум 60% слов запроса в заголовке. Возможны неточные совпадения: это не поиск по аудиоотпечатку.
- CAPTCHA, вход, программы и Telegram-боты отражены в отчёте. Monochrome, Lucida и другие неподдерживаемые интерфейсы можно открыть вручную. Недоступный сайт можно выбрать через «Все, включая недоступные» и повторить поиск.
- Обновление каталога сохраняет проверки для неизменившихся адресов; новые сайты остаются непроверенными. Экспорт JSON включает показанные результаты и статусы источников.

## Проверка и разработка

python -m unittest -v — 16 тестов. node --check static/app.js — синтаксис интерфейса.

python audit_sources.py — повторная сетевая проверка всех источников, сохраняет sources.json, занимает несколько минут. python catalog.py создаёт каталог заново из fmhy-audio.md и сбрасывает проверки; обычное обновление делайте кнопкой интерфейса.

Живые запросы: ARCOD/Massive Attack — 20 записей; TIDAL DL/Massive Attack — 25 треков; Khinsider/Mario — 570 ссылок; Classical Music Download/Bach — 13; BurningTheGround/Depeche Mode — 4. Это результаты тестов, не гарантия полноты каталогов.

Сервер слушает только 127.0.0.1, проверяет источник POST-запросов, ограничивает размер ответа и запрещает внутренние сетевые адреса. Для публичного размещения требуется дополнительная защита.
